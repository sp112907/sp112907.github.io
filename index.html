About

關於我

畢業於朝陽科技大學資訊管理系，自 2016 年起投入軟體工程，主要專注在 Web 後端、全端開發、系統整合與技術研究。

做過會員與管理後台、交易與金流系統、營運數據報表、內容平台、廣告機系統、遊戲相關系統、自動化工具及 AI 應用，具 Web 介面規劃、版面設計、配色、切版及前後端功能開發經驗；也負責 Linux、Docker、GCP 與網路環境的建置與部署。

下一階段希望以資深軟體工程師為方向，持續深化 System Design、軟體架構、測試與工程化能力。

  1. 國中一年級

    開始研究網頁程式設計，和當時的無名小站站長們一起做線上音樂播放器與 Flash 動畫。

  2. 國中二年級

    開始研究 Windows 視窗程式與線上遊戲伺服器架設。

  3. 國三暑假

    成功架起人生第一個 RO 私服，並用 VB.NET 寫出第一支遊戲啟動器。

  4. 高職

    因家人期待就讀餐飲科，打工與下課之餘繼續自學，開始接觸 PHP 與更多線上遊戲架設。

  5. 大學

    跨科考上資管系，精進網頁、視窗程式與伺服器技術，也接觸了動畫設計。

  6. 2016 至今

    進入軟體公司，從助理工程師一路走到全端與後端工程師。
