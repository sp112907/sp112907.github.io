Palworld 伺服器控制台

幻獸帕魯伺服器管理工具：私服 GM 等級的控制台

概述

以 Electron + React + TypeScript 打造的繁體中文桌面工具。除了一鍵啟動與更新伺服器，還能即時修改遊戲數值並直接套用到遊戲內、在即時地圖上追蹤所有玩家位置、管理玩家與公告，像私服 GM 工具一樣掌控整台伺服器。

重點功能

  • 一鍵啟動、停止與更新伺服器（整合 SteamCMD）
  • 即時修改遊戲數值並直接套用到遊戲內（大部分數值即時生效，少數參數需重開伺服器）
  • 即時地圖追蹤所有玩家位置，支援兩點點擊座標校準
  • 玩家管理：踢人、封鎖、解封與全服公告（REST API）
  • 108 項官方參數視覺化設定，引號與括號感知的 INI 引擎，無失真往返並保留未知鍵，存檔前自動備份
  • 世界存檔排程備份與輪替；狀態列即時顯示 CPU、記憶體與平均延遲

我負責的部分

  • 從自己架設帕魯伺服器的痛點出發定義需求：哪些操作要一鍵完成、哪些數值要能即時套用到遊戲內。
  • 決定架構邊界：REST API 的連線與認證都在 Electron 主行程進行，介面只能呼叫 preload 暴露的 IPC 白名單。
  • 逐項驗收：用真實的 PalWorldSettings.ini 檢查讀寫不失真，並在實際伺服器上確認玩家管理與地圖座標。

挑戰與做法

官方 INI 把所有參數擠在一行 OptionSettings=(...)，值裡可能有引號與括號，一般 INI 套件會切壞。
要求引號與括號感知的解析器，並以「讀進再寫出必須與原檔一致」作為驗收條件，未知的鍵原樣保留。
地圖圖片的像素座標和遊戲世界座標不一致，玩家位置會畫歪。
設計兩點點擊校準：在地圖上點兩個已知位置，換算出縮放與位移。
直接改設定檔，一旦寫壞就可能讓伺服器起不來。
每次存檔前自動備份設定檔，世界存檔另外排程備份並輪替保留份數。

現在回頭看

  • AI 產出程式碼很快，但需求和驗收條件沒寫清楚時就會偏掉；這個專案讓我習慣先寫清楚「怎樣算做完」。
  • 自動化測試是我檢查 AI 產出最可靠的方式，INI 引擎的往返測試就是這樣把關的。
