PzShop 自行車商城

從零手刻的電商前台：商品、購物車、會員與結帳

概述

以原生 PHP 搭配 MySQL 撰寫的自行車電商網站，包含輪播主視覺、商品分類、購物車、會員註冊登入、忘記密碼與付款流程。

重點功能

  • 自建路由與頁面權限機制
  • 購物車與訂單流程
  • 會員註冊、登入與忘記密碼
  • 響應式商品列表

我負責的部分

  • 獨立完成前台所有頁面：首頁輪播、商品列表與商品頁、購物車、會員註冊登入、忘記密碼與付款流程。
  • 自己設計共用的 PHP 核心：路由白名單、加密網址、會員登入與資料庫連線封裝。
  • 規劃 MySQL 資料表：商品、會員、購物車、訂單與登入紀錄。

挑戰與做法

網址若直接對應 PHP 檔案路徑，任何人都能猜測並存取內部檔案。
所有請求經 .htaccess 導向單一入口；網址參數是加密後的「網站｜頁面｜動作」，解密後到白名單路由表查對應檔案，查不到就導向 404。
沒有框架，每支頁面都要自己存取資料庫，很容易寫出 SQL injection。
把 PDO 連線包成共用類別，查詢一律使用 prepare 與參數綁定。

現在回頭看

  • 密碼當年用 md5 雜湊，今天會改用 password_hash（bcrypt 或 Argon2id）。
  • 自建路由和加密網址是很好的練習，但今天會選 Laravel 這類成熟框架，把心力放在商業邏輯。
  • 當年全靠手動點測，今天會從第一天就寫自動化測試。
